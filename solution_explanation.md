# Expert approach to the ZnO XRD characterisation task

The supplied measurement is a powder X-ray diffraction scan of one nanocrystalline zinc oxide sample. An expert should begin by inspecting the data structure and the two-theta range, rather than treating every exported column as a legitimate experimental observation. Only measured intensity may support the analysis. Calculated-pattern, fitted-background, and difference columns from a previous refinement are analytical products, not raw measurements. Retaining them would prejudice phase identification and line-shape interpretation.

The first scientific question is phase assignment. The prominent reflections near 31.8, 34.4, and 36.3 degrees two-theta are characteristic of the hexagonal wurtzite form of ZnO. Assignment should use multiple peaks over the scan range rather than one intense reflection, because a single peak can be coincidental, shifted, or affected by preferred orientation. An expert should inspect the complete measured range for unassigned sharp reflections and should phrase any conclusion carefully: a scan may support a primary crystalline phase but cannot prove the absence of amorphous material or every trace impurity.

For the hexagonal structure, the d spacings calculated from Bragg's law are jointly related to the lattice constants a and c. Combining several indexed reflections is preferable to estimating a parameter from one peak because it averages random peak-location error and makes systematic disagreement visible. The unit-cell volume follows from the hexagonal geometry. Results should include units and sufficient reflection-level information for another scientist to audit the calculation.

Peak breadth requires more care than peak position. A local background must be separated from each diffraction feature, and peak width should be measured consistently. Broadening can reflect finite coherent-domain size, microstrain, defects, sample displacement, preferred orientation, and the instrument response. Combining broadening from several reflections in a Williamson-Hall-style trend provides an apparent domain-size and strain estimate, but the inference has assumptions. It is useful as a compact microstructural descriptor, not as proof that physical particles have that diameter.

The available metadata explicitly states that no instrument-standard scan was supplied. The proper scientific response is therefore to report an apparent coherent-domain size, set the instrument-correction flag to false, and explain the limitation. Subtracting an invented instrument contribution would give an unjustified precision. The same restraint applies to secondary phases: the result should say whether additional crystalline peaks are resolved in the supplied interval, not assert chemical purity beyond the information in the scan.

Finally, the JSON output should be treated as an analytical record, not merely a numerical answer. It should name the phase model, preserve all reflection-level values, state the assumption that Cu K-alpha wavelength is used, and identify limitations. The accompanying report should interpret the lattice and broadening results in ordinary scientific language. This combination makes the work reproducible and lets the automatic verifier recompute the central conclusions from the observed two-theta and intensity values alone.
